# Contributing

This repository contains the Hacker House Goa 2026 Task #3 face identification and blockchain verification project.

## Development workflow

1. Create a focused branch from `main`.
2. Keep changes scoped to one pipeline stage or documentation update.
3. Test the CLI workflow locally before opening a pull request.
4. Never commit API keys, wallet credentials, private keys, generated artifacts, or local environment files.

## Pull requests

Describe the pipeline stage changed, how it was tested, and any external services or environment variables required.

## Commit messages

Use concise messages such as:

```text
feat: improve reverse search handling
fix: validate blockchain response
docs: update setup instructions
```
