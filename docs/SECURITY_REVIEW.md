# Security Review Checklist

- [ ] No private keys or API secrets are committed.
- [ ] Uploaded test images are permitted for use.
- [ ] External results are treated as untrusted.
- [ ] RPC and transaction errors are handled.
- [ ] Hash verification claims are limited to integrity.
- [ ] Logs exclude sensitive personal data.
- [ ] Demo configuration uses testnet resources.

Review these items before sharing a build or recording a demonstration.
