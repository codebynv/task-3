# Verification Checklist

Before demonstrating integrity verification:

- [ ] Confirm the canonical record fields.
- [ ] Recompute the record fingerprint.
- [ ] Compare it with the stored fingerprint.
- [ ] Modify a test field and confirm the fingerprint changes.
- [ ] Keep the original chain record unchanged during tamper testing.
- [ ] Explain that a hash match verifies integrity, not real-world identity.

Use test data and a testnet environment for demonstrations.
